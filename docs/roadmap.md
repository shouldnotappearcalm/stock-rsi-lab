2. **冻结一个真实投资实验。** 明确经济假设、策略家族、收益兑现期限和反证；
   冻结开发/验证/封存清单及持有期purge/embargo、费用模型和搜索预算。先做无agent

   多skill采用分别校准或策略预算，不能直接合并内部百分位。
4. **再研究严格RSI。** 保存模块父子谱系、冻结对照、合并后全回放、失败回滚；
   让改进器在新任务/新情境的提案效率获得可复验增量。封存评估使用独立进程/权限，
   单独管理重复查询预算。最后才接前向paper观察，仍不自动提交真实订单。
