# CSI500 主板财报公告事件：全量数据验收与一次 ORJ 诊断

这是对 [Lan 等（2024）](https://doi.org/10.1016/j.irfa.2024.103460)提出的“公告后隔夜反应可能预示后续价格延续”的**本地改编检验**。论文覆盖全 A 股、截至 2023 年 4 月，并结合投资者注意力设计按季度操作的组合；本项目使用 2024–2025 的历史 CSI500 主板成分、保守延迟入场及不同的数据源，不能搬用论文报告的收益。

先固定数据边界，再读取任何前向收益。已推送的采集脚本对 2024–2025 曾进入 CSI500 的 501 只主板股票查询 [巨潮公告](https://www.cninfo.com.cn/new/hisAnnouncement/query)，按股票逐份保存原始 ID、标题、日期和文件路径。独立的 [BaoStock 除权除息事件接口](https://github.com/zxygithub/baostock/blob/master/docs/pythonAPI.md)用于排查开盘日碰上已列出的公司行动。所有公告都按**日期级**处理，最早在公告日收盘后可见；次一交易日开盘反应被观察后，再下一交易日收盘才作为模拟入场。数据输入、价格文件和一次性检验规则的哈希记录在[预注册协议](../../experiments/qlib/orj-signal-pre2026-plan.json)。

| 数据验收 | 结果 |
| --- | ---: |
| 历史 CSI500 主板股票 | 501 |
| 巨潮四类报告记录 | 6,141 |
| 分类缺失后全文回查补回 | 4 |
| 初始标题规则不能识别的“股票 × 类型 × 年份” | 44 |
| BaoStock 复权事件记录 | 1,173 |
| 修正明确标题后可识别原始报告事件 | 3,985 |
| 信号日不在 CSI500 | 894 |
| 同一报告财年有多个原始版本 | 38 条，隔离 |
| 缺价 / 信号次开盘有列出的除权日 | 4 / 3 |
| 有价格配对、未列出除权日的事件 | 3,046 |
| 同股同信号日合并后的信号 | 2,741 |

标题为“某年报告.docx”或“某年报告（全文）”可明确识别；“锦江酒店年报”一类无财年的标题仍隔离，不能根据发布日期猜财年。原始报告时间几乎都显示 00:00，不能当成真实发布小时。初版检查错误地把 Qlib `factor` 的普通日间微小抖动当公司行动，造成大量误剔除；那份初跑结果未入库，最终[数据准入记录](../../experiments/qlib/cninfo-csi500-event-data-2026-10-17.json)使用独立除权日期。BaoStock 的历史记录本身仍无完整性保证，故“没有列出的除权日”不等于“公司行动已彻底排除”。

在看结果前，`fd6794f` 冻结了一次诊断：同股同信号日计一次，隔夜反应大于 0 的事件与其余事件分组；60 个交易日为主窗口、20 日为预设辅助窗口；股票后续复权收盘收益减中证 500 同期收益，再扣简化的 20bp 往返成本。只要 60 日正组的按信号日等权超额或相对非正组的优势不为正，即拒绝其作为开发候选。这不是账户组合回测。

| 指标 | 正隔夜反应 | 非正隔夜反应 |
| --- | ---: | ---: |
| 20 日可评估事件 | 1,373 | 1,364 |
| 20 日事件等权、扣成本超额 | -0.37% | +0.05% |
| 20 日按信号日等权、扣成本超额 | **-0.89%** | -0.73% |
| 60 日可评估事件 | 1,187 | 1,175 |
| 60 日事件等权、扣成本超额 | +0.15% | **+0.75%** |
| 60 日按信号日等权、扣成本超额 | **-1.06%** | +0.33% |

正组相对非正组的事件等权超额差在 20 日和 60 日分别为 **-0.43、-0.60 个百分点**，预定开发闸门失败。[机器结果](../../experiments/qlib/orj-signal-pre2026-results.json)保留覆盖、删失、费用假设和哈希。不能根据这次失败改成“买负 ORJ”、补挑日期或持有期；这些事件收益大量重叠，也没有形成可投资的净值曲线，更没有任何 2026 验证。以后若要推进财报因子，应提出独立的新经济假设和数据协议，而非反向解释这段结果。
