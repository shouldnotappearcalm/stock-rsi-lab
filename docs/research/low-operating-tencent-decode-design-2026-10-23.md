## Choice and source boundary

upstream wrapper. It validates JSON structure while skipping ignored values
without decoding them. Only object keys on the selected path, root code0 and
data/<expected lowercase code>/day are inspected. Accept raw JSON or exactly
kline_day2023 assignment framing with optional whitespace/terminal semicolon.
Reject malformed JSON, duplicate keys on traversed objects, absent/wrong stock,
adjusted-only arrays, trailing content, >1MiB or >64nested containers.
The skipped current quote branch remains opaque; the selector is shared by the
producer and separate projector checker, a disclosed common boundary.

For each day array row, lexically locate tokens first. Decode only its date,
require canonical explicit session2023-12-29..2025-12-31 and strict increasing
order, then decode selected numeric tokens. No whole row/day-array decoding.
