# 原股账户来源覆盖校验接线修正（无收益结果）

冻结版本 c789b42 的初次调用直接运行脚本，未把仓库根目录加入模块路径，导入 scripts 失败。改用 `PYTHONPATH=src python -m scripts.run_low_beta60_raw_development` 后，账户及输出目录创建前，在联美控股 2024-12-27 参考价变化处被旧覆盖校验拒绝。两次 traceback 原样保留在 `experiments/qlib/low-beta60-raw-daily-v1-preflight-failures.json`，未生成账户、收益或网络请求。

原因是新增编排向覆盖校验传了供应商原包，而该包缺失一笔已有公告证明且已独立编译的分派；事件引擎与覆盖校验看到了不同的事件集合。修正只在全部摘要核对、重新编译且与独审事件/回执精确相等后，复制源包并用验证后事件日期构造临时覆盖视图。已有覆盖函数继续检查所有参考价变化、复权标签与日期，不跳过异常，不从复权因子合成权益。原始包及完整事件经济字段均不改；账户仍用同一 179 个已审查事件。

新增合成回归先观察缺失入口失败，修正后验证：原包仍被旧检查拒绝；同源公告补充分派能解释除权日；移除事件后仍拒绝；源包完全不变。全部 400 项回归通过。实际 69 包、179 事件只做覆盖校验也通过，尚无 ROI。保留原 v1 请求，另冻结 v2 请求及本说明后再执行同一 100 万、额外 20/40 bps、2024—2025 工程诊断，投资和费用参数不变。

原协议的“来源失败保留最后账户状态”仅适用于已创建账户的阶段；preflight 失败尚无账户，保留运行日志及异常。日线代理、税压测和 2026 禁止准入的限制保持原协议规定。
