# 低贝塔十个公司行动来源问题

本阶段只查已捕获源数据中的四笔非现金分派和六个未配对复权日期，不改投资方法或源行情，不从调整因子推算现金/股数，也不计算账户收益或读取 2026 市场值。

范围绑定 69 股捕获清单、独立源审计和全部包摘要。复用已认证的五份实施公告：九州通、常熟银行两份、坤彩科技和联美控股；逐份绑定原 reviewed-manifest、元数据、PDF 字节与 SHA。四笔非现金税基由公告内容重新确认，不因为旧实验曾使用就自动准入。

其余五个问题按原分派行提供的公司与实施公告日查巨潮：中南传媒、广州港、凤凰传媒的 2024-07-05，招商积余的 2025-08-06，滨江集团的 2025-07-31。待核对的调整日期分别是 2024-07-15、2025-08-14、2025-08-08；这里只登记“可能对应更早分派”的来源问题，不预设其为基准、重复或新增分红。

请求冻结后先 push，再执行。五个新问题各最多两个精确日期列表页和一份唯一实施公告 PDF，共最多 15 个持久 HTTP 查询预约。每身份一次尝试，重启复用响应，未知/失败仍消耗预算；连续三个问题失败则留停止标记并拒绝自动续跑。查询仅针对 2024/2025 指定公告日，PDF 路径须匹配证券、日期和数字公告 ID；禁止重定向。20 秒 socket 超时、10 MiB 上限、请求间至少 0.3 秒，文件锁防并发。保留 HTTP 原字节和错误后再做语义校验。

抓取与内容审查分开。捕获器不授予税务、原股回放或投资准入；后续审查逐项对比公告的每股金额/股数、登记/除息/支付/到账日和税基，并保留任何差异。尤其招商积余供应商现金额只有六位小数，须检查原公告精度，不能默认为精确相等。只有确证的原公告补充项能进入另行冻结的事件编译，所有原包保持不变。

新增三项行为回归验证：复权记录只生成来源问题而不生成权益，审计行必须匹配已认证源包，重复或 2026 日期必须拒绝。共享 HTTP 捕获和预算模块保持已有版本，其原字节留存、截断/断线/重定向拒绝与跨重启预算回归继续适用。
