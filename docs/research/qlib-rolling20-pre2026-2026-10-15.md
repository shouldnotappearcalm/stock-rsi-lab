# Qlib 20-session rolling refit probe

Qlib's [dynamic benchmark](https://github.com/microsoft/qlib/blob/54355232463878d2eebb91fe0ee5fa7fa1f5976c/examples/benchmarks_dynamic/README.md) motivates a 20-session forecast horizon and rolling adaptation to concept drift. The fixed 20-session LightGBM candidate returned only 13.62% annualized in our pre-2026 development run, so this experiment changed **only** model refit timing. The label, Alpha158 features, model parameters, Top100/Drop5 portfolio, costs and 2024-01-02—2025-11-28 evaluation interval remained fixed.

The script was committed at `bc29320` before the run. It fitted 24 LightGBM models, one per 20-session prediction block. Each fit used the preceding 968 trading sessions for training and 242 for validation; both boundaries were purged by 21 sessions so no future return label reached the prediction date. Every test label matured by 2025-12-29.

| Metric | Rolling refit | Fixed model |
| --- | ---: | ---: |
| Net compound return | 24.66% | **27.54%** |
| Net annualized return | 12.27% | **13.62%** |
| 2024 net return | **1.06%** | 0.22% |
| 2025 net return through Nov 28 | 23.36% | **27.26%** |
| Compound excess over CSI500 | -4.85 pp | **-1.98 pp** |
| Average exposure | 99.58% | 99.67% |
| Maximum drawdown | **-21.65%** | -22.90% |
| Turnover / initial capital | **47.32x** | 47.61x |
| Cost / initial capital | **4.69%** | 4.71% |

The rolling rule slightly improved 2024 and drawdown but worsened total and excess return. It failed the 20% annualized development target. No refit frequency, training span, model parameter or portfolio change follows from this result. Full 24-window receipts and hashes are in [`rolling20-pre2026-results.json`](../../experiments/qlib/rolling20-pre2026-results.json). This is adaptive development evidence; the consumed 2026 interval remains excluded.
