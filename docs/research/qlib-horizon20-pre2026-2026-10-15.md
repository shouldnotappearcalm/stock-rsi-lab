# Qlib 20-session target probe

The [Qlib dynamic benchmark](https://github.com/microsoft/qlib/blob/54355232463878d2eebb91fe0ee5fa7fa1f5976c/examples/benchmarks_dynamic/README.md) uses a 20-session Alpha158 label. That supplied an independent reason to check whether our one-session return target mismatched a portfolio whose holdings turn over across weeks.

The candidate was frozen in commit `b89e550` before evaluation. It kept Qlib's reference LightGBM parameters, Alpha158 features and simulator costs. The sole change was a return label from the next session through 20 sessions later, paired with a fixed Top100/Drop5 portfolio (roughly 20-session full replacement). Training ended 2021-11-30, validation ended 2023-11-30, and the development backtest ran 2024-01-02 through 2025-11-28. The latest label input was 2025-12-29; no 2026 market fact was requested.

| Metric | Development result |
| --- | ---: |
| Net compound return | 27.54% |
| Net annualized return | **13.62%** |
| 2024 net return | **0.22%** |
| 2025 net return through Nov 28 | 27.26% |
| CSI500 compound return | 29.51% |
| Compound excess | -1.98 percentage points |
| Average exposure | 99.67% |
| Maximum drawdown | -22.90% |
| Turnover / initial capital | 47.61x |
| Cost / initial capital | 4.71% |

The 20% annualized development target failed. Matching the label to the turnover cycle did not improve the economic outcome in this one fixed configuration, so this candidate is rejected. The report is development evidence only; Qlib still uses close execution and a simplified price-limit threshold. Full metrics, data cutoffs and hashes are in [`horizon20-pre2026-results.json`](../../experiments/qlib/horizon20-pre2026-results.json).
