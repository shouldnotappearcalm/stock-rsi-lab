# 2017 年公开 A 股策略：来源抽象与冻结回放协议

本批只研究三份在原始发布方 Git 仓库中可追溯的 A 股教学代码。它们是公开明确规则的候选来源，不是交易者实盘盈利证明；不以网站宣传的收益选择候选。

## 原始来源与边界

从 https://github.com/ricequant/rqalpha 克隆历史，选择提交 `64937228246d658892fc28d0cb17f1aeeabe1c1b`。作者与提交时间都是 `2017-04-07T22:32:40+08:00`。三份文件、Git blob 身份、原始 commit 对象、当时 Apache-2.0 许可证和未采用来源的原因均保留在 `experiments/published-strategies/`。Git 自报时间是可审查历史证据，不是可信时间戳机构鉴证，也不是当时实盘执行的证明。未用 2024 年以后的教学修订替代旧版本。

## 明示适配假设

每个实际交易日15:05只唤醒一次，使用完整前一收盘可见窗口和实际账户；订单在下一实际交易日09:30按日线开盘价代理成交。盘后bar到达设定是重建约定，未证明供应商当时实际到达时间。日频不模拟盘中消息、盘口、集合竞价队列或盘中止损。

原代码100%仓位改为本项目95%权益上限，保留5%现金；不为制造高仓位而在没有信号时补仓。金叉仅有穿越才买，不把处于多头排列等同于穿越；从2024年初现金账户开始，2023年数据只作指标热身，不虚构2023持仓。MACD和RSI也从同一初始现金状态开始。

RSI原来在回调中按股票顺序下单。本实现先以收盘账户冻结意图、依次预留买单现金，禁止用次日尚未成交卖单收入预算。买卖相同证券不会在同一决策出现；失败成交不改变信号持仓输入。由此与原平台可能即时更新现金的执行语义存在明确区别。归一化股数按已知factor换算100股买入单位；这是复权账户工程筛查，不是原始整数股与公司行动验收。

## 数据与账户

只复制原始固定3只股票和既有中证500对照指数的6字段行情字节前缀。保持原交易日表，物理截止2025-12-31，不读2026报价尾部；目录含名单、日历与哈希清单。原始大归档的日期/上市区间元数据可用于裁剪，不能解码未来行情。没有从本轮后验走势选股。由于源代码直接指定股票，本轮不使用财报队列，旧财报策略的100只门槛完全不变。

每个候选独立连续100万元账户，2024-01-02至2025-12-31，年间不重置。基础单边买5/卖15基点，最低5元，额外每边20与40基点各运行一次，共6个账户。Qlib归一化日线包含公司行动调整，不能等同于已验证分红现金、税费、历史ST标志、真实整数股及T+1账本；普通主板9.5%开盘涨跌幅过滤也不能替代逐日真实价格边界。均明确标记为工程筛查，不可据此宣称投资资格。

所有决策保存完整窗口日期/值、指标、实际现金与持仓、已知收盘/factor、买卖意图、as_of及快照hash；保存每日账户、订单含未成交、持仓、费用和报告。复核每次决策的权益/持仓等于前一收盘账户，所有历史日期不超过as_of，并逐日核对现金/费用/市值和净值。

## 冻结与晋级

冻结请求在实际计算前提交：绑定全部方法、skill、原来源、参考指标、数据字节和Python/Qlib/numpy/pandas版本。新输出目录禁止覆盖。保留失败与六组全部结果，不把部分失败后的收益当完整结果。

固定晋级条件：40基点账户2024、2025各自净收益严格大于0，平均仓位至少90%，未验证持仓估值为0。20基点是成本敏感性报告，不能替代40基点失败。没有按本批收益排序后新增第四候选或调门槛；这组仓位门槛是项目既有研究目标，不是已证明的统计最优值。

只有通过筛查的候选才可进入原始数据、公司行动、真实账户验证；该验证通过后另外提交冻结相同规则的2026扩展，再运行2026。2026的既有归档截止2026-10-21，不能冒充全10月，旧暴露意味着只能叫前向应用。不得用2026结果变更阈值、股票、持仓、时钟、成本或数据门槛。若本批无候选通过，2026保持null、未访问，直接记录拒绝；不是收益为0。
