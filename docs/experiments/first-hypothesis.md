# 首个可反证实验

工作假设是中期上升中的短期回撤。趋势使用可见窗口首尾收益，回撤使用短窗口最高
收盘价到当前价的跌幅。经济解释是假设短期卖压暂时偏离持续趋势；趋势失效或长时间
未兑现可反证。该解释未获经验支持；初始10日/3日窗口是工程起点。

固定模块：数据可见性、明确日历、因子计算器、账户/费用、撮合、回放、验证入口。
可改模块：skills/trend-pullback/skill.json。当前四个候选分别修改最低回撤为0.5%
或3%、持有期限为2或8个交易日，全部相对冻结seed应用，仓位上限仍10%。
候选目录、费用和数据不能由提案修改。

五个离线arm：固定seed重复评估、网格、固定随机种子无放回搜索、开发反馈启发式、
打乱相同类型episode结果的反馈启发式。启发式不冒充LLM；另有显式codex arm。
每组共享一次seed基线，随后消耗相同候选**尝试**预算。重复/未知/报错提案占用次数，
有效评估数单独报告。候选只有开发净收益更高才更新best指针；这不是统计晋级门槛。

反馈包含三个开发期episode的行情与策略账户变化，保留case、时段、反馈hash、
原始提案、patch、skill hash、实际run及错误。shuffle旋转episode outcome，保留类型
和边际分布。每轮可读取上一轮评估反馈；候选仍限于同一个seed目录。
这是控制组与接口验证，**尚非改进器自身递归进化**。

当前合成开发期为2024-09-02至10-09，验证为10-10至10-11，封存为10-14至10-18。
这些很短的窗口只验证拒绝访问和时间边界，没有统计功效。正式实验必须重新冻结
足够长的真实PIT数据，按行情情境分块，设purge/embargo，避免持有期跨折叠泄漏，
事先登记同预算搜索、跨时期迁移、费用压力、实验选择偏差与多次查询预算。

VerifyGate首版实际实现：G0字段/时间/数据身份；G1快照因果性与未来扰动回归；
G2证据绑定/账户/成交约束；G3保存patch和实际运行skill hash；G4等尝试预算账本；
G5 campaign拒绝validation/sealed。G6未来paper和正式统计验收尚未实现。
后续须检验LLM对等预算搜索的增量，不能只比较弱seed。bootstrap改变的是置信区间，
不能要求原收益点估计随块长改变。收益阈值需要功效分析后再登记。
